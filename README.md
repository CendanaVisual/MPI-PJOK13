# MPI PJOK - Media Pembelajaran Interaktif

Website pembelajaran interaktif PJOK untuk Kelas 1 & Kelas 3 SD (Kurikulum Merdeka).

## Isi Website
- **index.html** → Gerbang pilihan kelas
- **kelas1.html** → MPI Kelas 1 (Nonlokomotor + Game)
- **kelas3.html** → MPI Kelas 3 (Nonlokomotor + Game)

## Cara Hosting di GitHub Pages

1. Buat repository baru di GitHub (contoh: `mpi-pjok`)
2. Upload semua file di folder ini ke repository (pastikan `index.html` ada di root)
3. Buka **Settings** → **Pages**
4. Di **Source**, pilih branch `main` (atau `master`) dan folder `/ (root)`
5. Klik **Save**
6. Tunggu beberapa menit, website akan tersedia di:
   `https://USERNAME.github.io/NAMA-REPO/`

## Link antar halaman
Semua menggunakan relative path (`kelas1.html`, `kelas3.html`, `index.html`) sehingga otomatis terhubung saat di-host di GitHub Pages.

## Fitur
- Tema soft & cerah
- Video animasi diputar di dalam website (modal)
